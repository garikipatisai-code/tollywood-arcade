# Launch Flow + Replay (APPROVED — blanket authorization)

Date: 2026-10-26 · Status: approved by owner (standing order).
Reproduced 2026-10-26 via screenshots: fresh landing = instant Sabotage with
no guidance; select reachable only via pause-menu "Story" link; locked cards
visually identical to unlocked; no Quick-Play return on select.

## Design

**Landing (egara/, Sabotage instant — v1 behavior preserved):** first-visit
welcome toast (only when zero chapter progress): "New here?" + [Story] CTA,
non-blocking (canvas clicks pass through), auto-hides in 8 s or on first
canvas pointerdown.

**Select (?select=1):** locked cards dimmed + 🔒 prefix; Quick-Play card on
top (→ Sabotage, no data-chapter attr so existing counts hold); per-card goal
line kept; NG+ toggle unchanged.

**Menus:** every menu gains a "☰ Chapters" link (→ ?select=1), replacing the
vague "Story" link. Pause, game-over, complete menus all lead home.
